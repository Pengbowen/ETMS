# 证书库模块 - 详细设计文档

## 1. 模块概述

证书库模块为 ETMS 培训管理系统提供完整的证书生命周期管理，支持证书模板配置、自动发放、真伪验证和批量导出。

### 1.1 核心功能
- **证书模板可视化配置**：背景图 + 文本占位符（姓名、课程、日期）+ 二维码定位
- **证书自动发放规则**：课程完成触发 / 考试通过触发
- **证书真伪验证**：扫码 / 编号在线核验
- **证书批量打印与 PDF 导出**

### 1.2 技术选型

| 层面 | 技术 | 理由 |
|------|------|------|
| 后端框架 | Spring Boot 3.3.4（项目一致） | 复用项目基础设施 |
| ORM | MyBatis-Plus + BaseMapper | 与项目现有模式一致 |
| 数据库 | MySQL 8.1 | 与项目一致 |
| 二维码生成 | Google ZXing (`com.google.zxing`) | Apache-2.0 开源，广泛使用 |
| 证书图片合成 | Java AWT + BufferedImage | JVM 内置，无额外依赖 |
| PDF 导出 | Apache PDFBox (`org.apache.pdfbox`) | Apache-2.0 开源，纯 Java |
| 前端框架 | React 18 + TypeScript + Vite | 与项目一致 |
| 图片裁剪 | react-easy-crop | 模板背景图裁剪定位 |
| HTML 转图片 | html2canvas（前端） | 模板预览实时渲染 |
| 批量下载 | JSZip + FileSaver | 前端打包下载 |

## 2. 数据库设计

### 2.1 证书模板表 `certificate_templates`

```sql
CREATE TABLE `certificate_templates` (
  `id` int(11) unsigned NOT NULL AUTO_INCREMENT COMMENT '主键',
  `name` varchar(100) NOT NULL DEFAULT '' COMMENT '模板名称',
  `background_image` varchar(500) NOT NULL DEFAULT '' COMMENT '背景图S3资源key',
  `width` int(11) NOT NULL DEFAULT 1200 COMMENT '模板宽度(px)',
  `height` int(11) NOT NULL DEFAULT 850 COMMENT '模板高度(px)',
  `placeholders` text COMMENT '占位符配置JSON',
  `qr_config` text COMMENT '二维码配置JSON',
  `status` tinyint(1) NOT NULL DEFAULT 1 COMMENT '状态[1:启用,0:禁用]',
  `admin_id` int(11) NOT NULL DEFAULT 0 COMMENT '创建人ID',
  `created_at` timestamp NULL DEFAULT NULL COMMENT '创建时间',
  `updated_at` timestamp NULL DEFAULT NULL ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='证书模板表';
```

**`placeholders` JSON 结构：**
```json
[
  { "key": "user_name", "label": "学员姓名", "x": 600, "y": 350, "fontSize": 36, "color": "#333333", "align": "center" },
  { "key": "course_name", "label": "课程名称", "x": 600, "y": 450, "fontSize": 24, "color": "#666666", "align": "center" },
  { "key": "issue_date", "label": "发证日期", "x": 600, "y": 550, "fontSize": 20, "color": "#999999", "align": "center" }
]
```

**`qr_config` JSON 结构：**
```json
{ "enabled": true, "x": 1000, "y": 650, "size": 120, "url_pattern": "/certificate/verify?id={cert_no}" }
```

### 2.2 证书记录表 `certificate_records`

```sql
CREATE TABLE `certificate_records` (
  `id` int(11) unsigned NOT NULL AUTO_INCREMENT COMMENT '主键',
  `cert_no` varchar(32) NOT NULL DEFAULT '' COMMENT '证书编号(唯一)',
  `template_id` int(11) unsigned NOT NULL DEFAULT 0 COMMENT '模板ID',
  `user_id` int(11) NOT NULL DEFAULT 0 COMMENT '学员ID',
  `user_name` varchar(64) NOT NULL DEFAULT '' COMMENT '学员姓名(冗余)',
  `course_id` int(11) NOT NULL DEFAULT 0 COMMENT '关联课程ID',
  `course_name` varchar(200) NOT NULL DEFAULT '' COMMENT '课程名称(冗余)',
  `cert_image` varchar(500) NOT NULL DEFAULT '' COMMENT '证书合成图S3路径',
  `status` tinyint(1) NOT NULL DEFAULT 1 COMMENT '状态[1:有效,0:已撤销]',
  `issue_type` varchar(20) NOT NULL DEFAULT 'manual' COMMENT '颁发方式[manual:手动,auto:自动]',
  `rule_id` int(11) DEFAULT NULL COMMENT '触发的规则ID(自动发放时)',
  `admin_id` int(11) NOT NULL DEFAULT 0 COMMENT '操作人ID',
  `issued_at` timestamp NULL DEFAULT NULL COMMENT '颁发时间',
  `revoked_at` timestamp NULL DEFAULT NULL COMMENT '撤销时间',
  `created_at` timestamp NULL DEFAULT NULL COMMENT '创建时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_cert_no` (`cert_no`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_course_id` (`course_id`),
  KEY `idx_template_id` (`template_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='证书记录表';
```

### 3.3 证书生成流程

```
1. 获取模板配置（背景图URL + 占位符坐标 + 二维码配置）
2. 从S3下载背景图 → BufferedImage
3. 在背景图上绘制文本占位符：
   - 替换 {user_name} → 学员姓名
   - 替换 {course_name} → 课程名称
   - 替换 {issue_date} → 发证日期
4. 生成二维码（含验证链接），绘制到指定坐标
5. 合成最终图片 → 上传S3 → 记录 storage_key
```

### 3.4 自动发放流程

```
事件触发（课程完成 / 考试通过）
  → 查询匹配的启用规则
  → 检查用户是否已获得该课程证书（防重复）
  → 调用证书生成服务
  → 写入 certificate_records 表
```

## 5. 关键技术方案

### 5.1 证书图片合成（Java AWT）

使用 `java.awt.Graphics2D` 在背景图上叠加文本和二维码：

```java
// 伪代码
BufferedImage bgImage = ImageIO.read(bgInputStream);
Graphics2D g2d = bgImage.createGraphics();
// 设置抗锯齿
g2d.setRenderingHint(RenderingHints.KEY_TEXT_ANTIALIASING, ...);
// 绘制每个占位符文本
for (Placeholder p : placeholders) {
    g2d.setFont(new Font("SansSerif", Font.PLAIN, p.fontSize));
    g2d.setColor(Color.decode(p.color));
    // 计算对齐后的X坐标
    int x = calcAlignedX(p, textWidth);
    g2d.drawString(resolvedText, x, p.y);
}
// 绘制二维码
g2d.drawImage(qrImage, qrConfig.x, qrConfig.y, null);
g2d.dispose();
```

### 5.2 PDF 导出（Apache PDFBox）

```java
PDDocument document = new PDDocument();
PDPage page = new PDPage(new PDRectangle(width, height));
document.addPage(page);
PDPageContentStream cs = new PDPageContentStream(document, page);
PDImageXObject image = PDImageXObject.createFromByteArray(document, pngBytes, "cert");
cs.drawImage(image, 0, 0, width, height);
cs.close();
document.save(outputStream);
document.close();
```

### 5.3 前端模板编辑器

使用 `react-easy-crop` 处理背景图裁剪定位，配合 Canvas 实现占位符拖拽编辑，使用 `html2canvas` 导出预览图。
