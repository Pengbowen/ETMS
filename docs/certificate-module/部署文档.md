# 证书模块 - 部署文档

## 1. 数据库迁移

执行 SQL 迁移脚本创建证书相关表：

```bash
# 方式一：Docker 环境
docker compose exec mysql mysql -u root -pplayeduxyz playedu < docs/certificate-module/migration.sql

# 方式二：直连 MySQL
mysql -h 127.0.0.1 -P 23307 -u root -pplayeduxyz playedu < docs/certificate-module/migration.sql
```

## 2. 权限初始化

证书模块新增了3个权限项，需要在 `admin_permissions` 表中手动插入或通过管理后台配置：

```sql
INSERT INTO `admin_permissions` (`type`, `group_name`, `sort`, `name`, `slug`, `created_at`) VALUES
('action', '证书管理', 0, '证书模板', 'certificate-template', NOW()),
('action', '证书管理', 5, '证书规则', 'certificate-rule', NOW()),
('action', '证书管理', 10, '证书记录', 'certificate-record', NOW());
```

然后给相应角色分配这些权限。

## 3. Docker 部署

前端代码已更新，后端新增模块 `playedu-certificate`，直接构建即可：

```bash
docker compose up -d --build
```

## 4. Maven 依赖说明

新增依赖（已包含在 pom.xml 中）：
- `com.google.zxing:core:3.5.3` — 二维码生成
- `com.google.zxing:javase:3.5.3` — 二维码生成（Java SE 扩展）
- `org.apache.pdfbox:pdfbox:3.0.1` — PDF 导出

## 5. 前端依赖说明

前端使用纯浏览器端方案，无需新增额外 NPM 依赖：
- 证书图片合成在后端完成（Java AWT）
- 前端仅负责管理界面 CRUD 和公众验证页面
