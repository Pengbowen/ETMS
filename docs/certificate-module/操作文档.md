# 证书模块 - 操作文档

## 1. 证书模板管理

路径：`课程中心 → 证书模板`

### 1.1 创建模板

1. 点击「新建模板」
2. 填写模板名称（如：完成证书）
3. 填写背景图 S3 路径（需先上传背景图到资源管理）
4. 设置模板宽高（默认 1200×850）
5. 配置二维码参数（可选）：启用、坐标、尺寸
6. 点击确定

### 1.2 模板配置说明

证书合成时会自动替换以下占位符：
- `user_name` → 学员姓名
- `course_name` → 课程名称
- `issue_date` → 发证日期

二维码内容为证书验证链接（格式：`/certificate/verify?id={cert_no}`）。

### 1.3 编辑/删除模板

列表页操作列可编辑或删除已有模板。

## 2. 发放规则管理

路径：`课程中心 → 发放规则`

### 2.1 创建自动发放规则

1. 点击「新建规则」
2. 填写规则名称
3. 选择证书模板
4. 选择触发类型：
   - **课程完成**：学员完成课程时自动发放
   - **考试通过**：学员通过考试时自动发放
5. 填写适用课程 ID（逗号分隔，留空表示所有课程）
6. 设置最小完成进度（默认 100%）

### 2.2 启用/禁用规则

编辑规则可修改状态（启用/禁用）。禁用的规则不会触发自动发放。

---

## 3. 证书发放记录

路径：`课程中心 → 发放记录`

### 3.1 手动发放

1. 点击「手动发放」
2. 选择证书模板
3. 输入学员 ID 和课程 ID
4. 点击确定

系统会自动生成证书图片（含二维码）并上传到 S3。

### 3.2 撤销证书

在操作列点击「撤销」，证书状态变为已撤销，扫码验证将显示失效。

### 3.3 导出 PDF

在操作列点击「导出PDF」，下载证书的 PDF 版本。

---

## 4. 证书真伪验证

### 4.1 扫码验证

证书图片上的二维码包含验证链接，扫码后跳转到：

`/certificate/verify?id={证书编号}`

### 4.2 编号验证

在验证页面输入证书编号，查询证书真伪和有效性。

验证结果包含：
- 证书编号
- 学员姓名
- 课程名称
- 模板名称
- 颁发时间
- 证书状态（有效/已撤销）

---

## 5. 注意事项

1. **背景图要求**：PNG 格式，尺寸建议 1200×850，需先上传到资源管理获取 S3 key
2. **字体支持**：当前使用 Java SansSerif 默认字体，中文显示正常
3. **防重复**：同一学员同一课程只允许发放一次证书
4. **自动发放**：需事件系统支持，当前版本通过手动调用触发
