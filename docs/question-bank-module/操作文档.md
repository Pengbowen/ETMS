# 试题库模块 - 操作文档

## 1. 入口

登录管理后台，左侧菜单栏点击「试题管理」进入。

## 2. 分类管理

### 2.1 查看分类树
左侧面板展示试题分类树，点击分类节点可筛选该分类下的试题。

### 2.2 新增分类
- 点击分类面板顶部的「新增」按钮，创建根分类
- 鼠标悬停在分类节点上，点击 `+` 号，创建子分类
- 弹窗中填写分类名称和排序值

### 2.3 编辑/删除分类
- 鼠标悬停分类节点，点击 `✎` 编辑，点击 `×` 删除
- 含子分类的节点不允许删除

## 3. 试题管理

### 3.1 查看试题列表
- 右侧表格展示试题，每行包含：题型标签、题干摘要、难度星级、标签、使用次数、操作
- 支持按分类、题型、难度、关键词筛选
- 分页浏览

### 3.2 新建试题
1. 点击「新建试题」按钮进入编辑页
2. 选择题型：单选题 / 多选题 / 判断题 / 填空题 / 问答题 / 完形填空
3. 选择分类和难度星级
4. 填写标签（逗号分隔，如：`Java,基础`）
5. 在题干富文本编辑器中输入题目内容，支持：
   - 加粗、斜体、下划线等文本样式
   - 插入图片（上传后自动嵌入）
   - 插入代码块
   - 可扩展数学公式（KaTeX）
6. 根据所选题型填写答案：
   - **单选/多选题**：添加选项，标记正确答案（圆形=单选，方形=多选）
   - **判断题**：选择正确/错误
   - **填空题**：添加填空位，填写正确答案和备选答案
   - **问答题**：填写参考答案和得分要点
   - **完形填空**：填写段落内容（用 `{{blank_0}}` 标记填空位），配置每个填空的选项和正确答案
7. 在「题目解析」中填写解析内容
8. 点击「保存试题」

### 3.3 编辑试题
点击试题行的「编辑」按钮，修改后保存。

### 3.4 删除试题
点击试题行的「删除」按钮，确认后删除（不可恢复）。

### 3.5 导出试题
- 顶部筛选栏设置所需筛选条件
- 点击「导出」按钮，下载 Excel 文件
- 导出字段：编号、题型、分类ID、题干（纯文本）、选项、答案、难度、标签、使用次数、创建时间

## 4. 使用次数

`use_count` 字段预留给后续考试中心模块使用。当试题被试卷引用时，该值自动递增。

## 5. 注意事项

- 题干和解析为富文本（HTML 格式），选项为普通文本
- 标签建议使用简短关键词，多个标签用逗号分隔
- 删除分类前请确保分类下无子分类
- 导出的 Excel 题干为纯文本（已去除 HTML 标签）
