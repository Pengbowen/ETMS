# 试题库模块 - 部署文档

## 1. 部署前提

- ETMS 主项目已正常运行（Java 17 + Spring Boot 3.3.4 + MySQL 8.1）
- Docker Compose 或独立部署方式均适用

## 2. 数据库迁移

### 2.1 自动迁移（推荐）

应用启动时 `MigrationCheck` 会自动检测并创建 `question_categories` 和 `questions` 两张表，无需手动操作。

### 2.2 手动执行（备选）

如果自动迁移因故未生效，可手动执行 SQL：

```bash
docker compose exec mysql mysql -u root -pplayeduxyz playedu < docs/question-bank-module/migration.sql
```

## 3. Docker Compose 部署

代码已包含在项目中，重新构建即可：

```bash
docker compose down
docker compose build --no-cache
docker compose up -d
```

## 4. 后端验证

```bash
# 编译
cd playedu-api && ./mvnw -B -Dmaven.test.skip=true compile

# 运行（IDEA 直接启动或 Maven）
./mvnw -pl playedu-api spring-boot:run
```

## 5. 前端验证

```bash
cd playedu-admin

# 安装新增依赖
pnpm install

# 开发模式运行
pnpm dev

# 生产构建
pnpm build
```

## 7. 新增表

| 表名 | 说明 |
|------|------|
| `question_categories` | 试题分类表（多级树形结构） |
| `questions` | 试题表（支持 6 种题型 + 富文本） |

## 8. 权限配置

部署后需要在管理后台「系统 → 管理员角色」中为新模块添加权限：

- `question-category`：分类管理权限
- `question`：试题管理权限
