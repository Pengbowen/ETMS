# 试题库模块 - 详细设计文档

## 1. 模块概述

试题库模块为 ETMS 培训管理系统提供完整的试题管理能力，支持六种题型的 CRUD、多级分类树管理、富文本编辑、批量导出等功能，为后续考试中心模块提供试题数据基础。

### 1.1 核心功能

| 功能 | 说明 |
|------|------|
| 六种题型 | 单选题、多选题、判断题、填空题、问答题、完形填空 |
| 富文本编辑 | 题干与选项支持图片、代码块、数学公式（KaTeX） |
| 多级分类树 | 无限层级分类，拖拽排序，支持试题移动 |
| 试题标签 | 灵活标签体系，支持多标签筛选 |
| 难度等级 | 五级难度（1-5），支持按难度筛选与组卷规则 |
| 使用次数 | 自动统计试题被试卷引用的次数 |
| 批量导出 | Excel 导出，支持按分类/题型/难度/标签筛选导出 |

### 1.2 技术选型

| 层面 | 技术 | 理由 |
|------|------|------|
| 后端框架 | Spring Boot 3.3.4 + Maven 多模块 | 与项目一致 |
| ORM | MyBatis-Plus 3.5.7 + BaseMapper | 与项目现有模式一致 |
| 数据库 | MySQL 8.1 | 与项目一致 |
| 富文本存储 | HTML 字符串 | 跨端渲染兼容，前后端统一 |
| 数学公式 | KaTeX（前端渲染） | MIT 开源，轻量无服务端依赖 |
| Excel 导出 | Apache POI | 项目已有依赖，支持复杂格式 |
| 前端框架 | React 18 + TypeScript + Vite 4 | 与项目一致 |
| 富文本编辑器 | @wangeditor/editor ^5.1.23 | MIT 开源，React 支持好，可扩展 |
| UI 组件库 | Ant Design 5.x | 与项目一致 |

## 2. 数据库设计

### 2.1 试题分类表 `question_categories`

```sql
CREATE TABLE `question_categories` (
  `id` int(11) unsigned NOT NULL AUTO_INCREMENT COMMENT '主键',
  `parent_id` int(11) unsigned NOT NULL DEFAULT 0 COMMENT '父级ID[0:根分类]',
  `name` varchar(100) NOT NULL DEFAULT '' COMMENT '分类名称',
  `sort` int(11) NOT NULL DEFAULT 0 COMMENT '排序(升序)',
  `admin_id` int(11) NOT NULL DEFAULT 0 COMMENT '创建人ID',
  `created_at` timestamp NULL DEFAULT NULL COMMENT '创建时间',
  `updated_at` timestamp NULL DEFAULT NULL ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  KEY `idx_parent_id` (`parent_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='试题分类表';
```

### 2.2 试题表 `questions`

```sql
CREATE TABLE `questions` (
  `id` int(11) unsigned NOT NULL AUTO_INCREMENT COMMENT '主键',
  `category_id` int(11) unsigned NOT NULL DEFAULT 0 COMMENT '分类ID',
  `type` varchar(20) NOT NULL DEFAULT 'single_choice' COMMENT '题型[single_choice:单选,multi_choice:多选,true_false:判断,fill_blank:填空,short_answer:问答,cloze:完形填空]',
  `title` text COMMENT '题干(HTML富文本)',
  `options` text COMMENT '选项/填空配置(JSON)',
  `answer` text COMMENT '答案(JSON)',
  `analysis` text COMMENT '解析(HTML富文本)',
  `difficulty` tinyint(2) NOT NULL DEFAULT 3 COMMENT '难度[1-5]',
  `tags` varchar(500) NOT NULL DEFAULT '' COMMENT '标签(逗号分隔)',
  `use_count` int(11) NOT NULL DEFAULT 0 COMMENT '使用次数(试卷引用次数)',
  `status` tinyint(1) NOT NULL DEFAULT 1 COMMENT '状态[1:启用,0:禁用]',
  `admin_id` int(11) NOT NULL DEFAULT 0 COMMENT '创建人ID',
  `created_at` timestamp NULL DEFAULT NULL COMMENT '创建时间',
  `updated_at` timestamp NULL DEFAULT NULL ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  KEY `idx_category_id` (`category_id`),
  KEY `idx_type` (`type`),
  KEY `idx_difficulty` (`difficulty`),
  KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='试题表';
```

### 2.3 JSON 数据结构

**单选题 options + answer：**
```json
// options
["选项A的HTML内容", "选项B的HTML内容", "选项C的HTML内容", "选项D的HTML内容"]

// answer（正确选项索引数组）
[0]
```

**多选题 options + answer：**
```json
// options（同上）
["选项A", "选项B", "选项C", "选项D"]

// answer
[0, 2]
```

**判断题 answer：**
```json
// true=正确, false=错误, 索引0为固定答案
[true]
```

**填空题 options + answer：**
```json
// options
{
  "content": "填空题题干模板，用 {{blank_0}} 和 {{blank_1}} 标记填空位",
  "blanks": [
    { "answer": "正确答案", "alternatives": ["备选答案1", "备选答案2"] },
    { "answer": "正确答案2", "alternatives": [] }
  ]
}

// answer（可选，存标准答案索引或直接存答案文本）
["正确答案", "正确答案2"]
```

**问答题 options + answer：**
```json
// options（空）
{}

// answer
{
  "reference_answer": "参考答案(HTML富文本)",
  "scoring_points": ["得分要点1", "得分要点2"]
}
```

**完形填空 options + answer：**
```json
// options
{
  "passage": "包含 {{blank_0}} 和 {{blank_1}} 的段落内容",
  "blanks": [
    {
      "blank_index": 0,
      "options": ["选项A", "选项B", "选项C", "选项D"],
      "answer_index": 2
    },
    {
      "blank_index": 1,
      "options": ["选项A", "选项B", "选项C", "选项D"],
      "answer_index": 0
    }
  ]
}

// answer（所有填空位的正确选项索引）
[2, 0]
```

## 3. API 设计

### 3.1 分类管理

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/backend/v1/question/category/index` | 获取分类树 | question-category |

| DELETE | `/backend/v1/question/category/destroy/{id}` | 删除分类 | question-category |

```json
{
  "parent_id": 0,
  "name": "Java基础",
  "sort": 1
```


## 6. 关键技术方案

### 6.1 富文本存储策略

- 题干 `title`：存储为 **HTML 字符串**，前端 wangEditor 编辑，服务端直接存储
- 选项 `options` 中的每个选项：存储为 **HTML 字符串**，支持图片/代码/公式
- 解析 `analysis`：存储为 **HTML 字符串**
- 图片上传：复用现有的 `/backend/v1/upload/minio` 接口，上传后返回 S3 URL 内嵌到 HTML 中

### 6.2 KaTeX 数学公式

在前端 wangEditor 中通过自定义插件集成 KaTeX：
- 编辑时：通过弹窗输入 LaTeX 公式，编辑器插入 `<span class="katex-formula" data-latex="E=mc^2">` 标记
- 预览/展示时：使用 KaTeX 的 `renderToString` 或 `katex.render` 将标记转换为渲染后的数学公式

### 6.3 Excel 批量导出

使用 Apache POI（项目已有依赖）：
- 导出格式：.xlsx
- 包含字段：编号、题型、分类、题干（纯文本提取）、选项、答案、难度、标签、使用次数、创建时间
- 支持按当前筛选条件导出
